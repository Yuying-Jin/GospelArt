開頭（固定）

方案：一個固定的開頭，加上可自由排列的區塊

內容還沒定，所以頁面不寫死有哪些段落。Studio 裡只有一份「關於頁」文件：上面是固定的開頭（標題、一句引言、一幅窗裡的畫）， 下面是一個區塊列表，編輯可以新增、刪除、拖動排序、暫時隱藏。每一種區塊在網站上有自己的樣子。 點上方「區塊標記」可以看到每塊是哪一種。

參考 apolloswatered.org 的「關於」

它在導航的「About」下面分成六個子頁，每頁一長段文字，結尾一節經文和一條奉獻橫幅。對到我們的區塊：

  1. Who We Are：一段長文、小標題、條列 → 文字。
  2. What We Do for You：幾項服務，各一個小標題、一段話、通往那項服務的連結 → 要點，每條加一個可選的入口。我們對應的是畫廊、展覽報導、電子報。
  3. Our Mission：使命一段、異象一句 → 新增 宣言：一兩句大字，前面一個小標籤。
  4. Our Team：照片、名字、職分、簡介；董事會、顧問只列名字 → 新增 人物：照片放在小拱窗裡，沒有照片時是一朵四葉；下面可以加一組只有名字的名單。
  5. Statement of Faith：很長的信經和條文 → 文字，加一個「折疊」選項，先顯示開頭，點了展開。
  6. FAQ’s：一問一答 → 新增 問答：一條一條展開，樣子同畫廊詳情裡的段落。
  7. 每頁結尾的經文 → 經文；奉獻橫幅 → 連結（奉獻等非營利身分確定後再說）。

Schema 草案

aboutPage                單一文件，id "aboutPage"，同首頁不能複製或刪除
├ title        localeString       頁面標題（空則用「關於我們」）
├ lede         localeText         一句引言，可空
├ heroArtwork  → artwork          窗裡的畫，只能選畫廊裡的；空則不顯示窗
└ sections[]   下面八種任選、可排序

  共通    heading  localeString   區塊標題，可空（經文、連結通常不要）
          anchor   slug           由英文標題自動產生，/about#who-we-are
          hidden   boolean        暫時不上線

  aboutText       body: localeRichText        新聞的富文本編輯器
                  folded: boolean             先顯示開頭，點了展開
  aboutPoints     items[2–4] { title, body: localeText,
                               link?: { label, to } }
  aboutStatement  items[1–2] { label: localeString,
                               text:  localeText }
  aboutFeature    body: localeRichText
                  image: → artwork 或上傳圖片
                  side: left | right
  aboutPeople     people[] { name, role: localeString,
                             photo?: image, bio: localeText }
                  roster?: { label, names[] }
  aboutFaq        items[] { question: localeString,
                            answer:   localeRichText }
  aboutScripture  reference + scripture       首頁結尾經文那套
                                               選經文和 Fetch
  aboutLinks      items[1–3] { label, to: 站內頁面 | 網址 }

從首頁借來的光和小元素

  1. 開頭的光束和塵埃：同首頁 hero，光從頂上照進窗裡的畫，顏色取畫的調色盤。比首頁收斂：光窄一點、淡一點，因為這頁的主角是文字。
  2. 尖拱窗：新的元素。開頭的畫和同工的照片都放在拱形窗框裡，讓人想到教堂的窗，又不搶畫。
  3. 區塊標題：同首頁的兩條漸隱金線，下面多一朵小四葉，每段都一樣，讀起來有節奏。
  4. 圖文的畫燈：同首頁「最新作品」亮著的那幅：頂邊一道亮光、牆上一圈畫的顏色。
  5. 要點：同首頁「我們是誰」，四葉分隔、兩側小花、淡淡的鉛條紋理。寬螢幕改成並排。
  6. 宣言：同首頁的宗旨大字；兩句並排時中間一道直的光。
  7. 經文：同首頁結尾，玫瑰窗在後面，中間留空讓經文清楚。
  8. 進場：區塊捲進畫面時從暗處亮起，減少動態效果時不動。

需要一起決定的

  1. 一頁，還是分子頁？參考網站分成六個子頁。我建議先做一頁加目錄：我們的內容目前不多，一頁讀完比較完整；導航「關於」下面可以像畫廊一樣展開一個子選單，連到各段（/about#our-team）。以後某段長到需要自己一頁（例如信仰告白），可以把「關於頁」從單一文件改成多份文件，每份一個子頁，區塊原樣搬過去，不用重做。
  2. 區塊種類。上面八種是不是都要？最少可以先做文字、要點、宣言、經文、連結，人物和問答等內容確定再加；加一種區塊不影響已有內容。
  3. 目錄。手機上是一排標籤，寬螢幕固定在左邊、跟著捲動點亮。區塊少的時候可以自動不顯示。
  4. 開頭的畫。建議同首頁，只能選畫廊裡的作品；也可以允許上傳一張照片（例如展覽現場）。
  5. 同工照片。人物區塊要不要放照片，還是只有名字和簡介。照片會是公開的。
  6. 字數上限。每個文字欄位都要有上限（標題、引言、要點、宣言、簡介、問題），數字是內容設計的決定，請你給。
  7. 英文標題做錨點。這樣 /about#our-team 可以分享、目錄可以跳。像新聞網址一樣，發布後固定不變。
